# Decision records

A selection of the architecture decision records (ADRs) behind BinoFit. The full set has 60; these five show how the app is shaped and why. Each one records the context, what was chosen, what else was considered and what it costs.

| # | Decision |
|---|---|
| [0001](0001-local-first-storage.md) | Local-first storage with cloud backup |
| [0002](0002-user-defined-meals.md) | Meals are user-defined |
| [0004](0004-tombstone-deletes.md) | Synced deletes are tombstones |
| [0028](0028-rest-mode-and-live-activity.md) | Rest mode and workout Live Activity |
| [0029](0029-heart-rate-from-apple-health.md) | Heart rate from Apple Health |

The source code is private, so file paths mentioned in these records point at code that is not in this repo.
